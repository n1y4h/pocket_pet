# pocket_pet
Meet Daisy! ♡

Pocket Pet is a beginner-friendly Python project where you can take care of your very own virtual pet, Daisy. Feed her, play with her, let her sleep, and keep track of her needs through an interactive terminal-based game.

This project was created to practice Python fundamentals while building something fun and interactive.

Features
> Interactive terminal menu
> ASCII pet expressions
> Feed, play, and sleep interactions
> Fullness, happiness, and energy stats
> Minimum and maximum stat limits (0–100)
> Dynamic pet moods based on happiness
> Interaction journal that tracks previous activities
> Custom goodbye screen

Built With
> Python 3
> Visual Studio Code
> Git and GitHub

How to Run
Clone or download this repository.
Open the project folder in VS Code
Open the integrated terminal.
Run the following command:
python main.py 

Meet Daisy and start playing!
